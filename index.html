Guide de Démarrage Rapide

MacroMaster est votre compagnon idéal pour suivre vos objectifs nutritionnels. Voici comment commencer :

  1. Configurez vos objectifs caloriques et macronutriments (protéines, glucides, lipides)
  2. Ajoutez vos repas quotidiens en utilisant notre base de données d'aliments
  3. Consultez vos statistiques pour suivre votre progression
  4. Utilisez la fonction de scan pour ajouter rapidement des aliments

FAQ - Questions Fréquentes

Comment scanner un code-barres ?

Appuyez sur le bouton de scan dans l'écran principal et pointez votre caméra vers le code-barres du produit.

Comment sauvegarder mes données ?

Vos données sont automatiquement sauvegardées dans le cloud. Connectez-vous simplement avec votre compte pour y accéder sur n'importe quel appareil.

Comment personnaliser mes objectifs ?

Dans l'onglet "Profil", appuyez sur "Objectifs" pour ajuster vos macros et calories selon vos besoins.

L'application est-elle gratuite ?

MacroMaster propose une version gratuite avec les fonctionnalités essentielles. Une version premium est disponible pour accéder à des fonctionnalités avancées.
