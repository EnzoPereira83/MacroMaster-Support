Guide de Démarrage Rapide

MacroMaster est une application simple et intuitive pour gérer vos macros quotidiennes. Voici comment commencer :

  1. Ouvrez l'application MacroMaster
  2. Créez votre profil en renseignant vos objectifs
  3. Commencez à enregistrer vos repas
  4. Suivez vos progrès dans l'onglet statistiques

FAQ - Questions Fréquentes

Comment modifier mes objectifs quotidiens ?

Allez dans "Paramètres" > "Objectifs" et ajustez vos valeurs selon vos besoins.

Comment ajouter un nouvel aliment ?

Cliquez sur le bouton "+" dans l'écran principal, puis "Nouvel Aliment". Remplissez les informations nutritionnelles.

Comment exporter mes données ?

Dans "Paramètres" > "Données", utilisez l'option "Exporter" pour sauvegarder vos données au format CSV.
