Politique de confidentialité

Introduction

Cette politique de confidentialité décrit comment MacroMaster collecte, utilise et protège vos données personnelles. Nous nous engageons à protéger votre vie privée et à traiter vos données de manière transparente.

Données collectées

Nous collectons les types de données suivants :

  • Données d'utilisation de l'application (interactions, temps d'utilisation)
  • Informations nutritionnelles saisies
  • Préférences de l'application
  • Données de suivi pour la personnalisation des publicités (avec votre consentement)

Utilisation des données

Nous utilisons vos données pour :

  • Fournir et améliorer nos services
  • Personnaliser votre expérience
  • Analyser l'utilisation de l'application
  • Afficher des publicités pertinentes (avec votre consentement)

Protection des données

Nous prenons la sécurité de vos données très au sérieux et mettons en œuvre des mesures de sécurité appropriées pour les protéger :

  • Chiffrement des données sensibles
  • Stockage sécurisé sur des serveurs protégés
  • Accès limité aux données personnelles
  • Mises à jour régulières de sécurité

Vos droits

Vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier vos données
  • Supprimer vos données
  • Retirer votre consentement pour le suivi publicitaire
  • Exporter vos données

Contact

Pour toute question concernant cette politique de confidentialité ou vos données personnelles, contactez-nous à :
